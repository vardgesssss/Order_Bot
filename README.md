# Order Bot

Telegram-бот для автоматизации приёма заказов в кондитерской. Реализует каталог товаров, корзину и многошаговое оформление заказа с выбором способа получения, даты и времени.

## Что делает

Бот автоматизирует процесс приёма заказов в Telegram с реализацией:
- Каталога товаров с фотографиями, описаниями и ценами
- Корзины для выбора и управления товарами
- Многошагового оформления заказа (FSM) с валидацией данных
- Выбора способа получения заказа (самовывоз или доставка)
- Выбора даты и времени получения с учётом доступных временных слотов
- Управления расписанием работы (циклы работы/выходных, рабочие часы)
- Системы оплаты переводом на карту с подтверждением платежа
- Автоматических уведомлений менеджеру о новых заказах с полной информацией

## Стек

- **Python 3.8+**
- **aiogram** (3.5.0) - асинхронный фреймворк для работы с Telegram Bot API
- **python-dotenv** (1.0.1) - загрузка переменных окружения
- **aiohttp** (3.9.1) - асинхронный HTTP клиент

## Как запустить

### Локальная разработка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd Order_Bot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` в корне проекта:
```
BOT_TOKEN=your_telegram_bot_token
MANAGER_CHAT_ID=your_manager_chat_id
```

4. Запустите бота:
```bash
python main.py
```

### Деплой на Railway

1. Создайте новый проект в Railway
2. Подключите репозиторий
3. Railway автоматически определит `Procfile` и запустит бота
4. Добавьте переменные окружения в настройках проекта:
   - `BOT_TOKEN` - токен Telegram бота
   - `MANAGER_CHAT_ID` - ID чата менеджера для уведомлений

### Деплой на Heroku

1. Создайте новое приложение в Heroku
2. Подключите репозиторий
3. Heroku автоматически определит `Procfile` и `app.json`
4. Добавьте переменные окружения в настройках приложения:
   - `BOT_TOKEN` - токен Telegram бота (обязательно)
   - `MANAGER_CHAT_ID` - ID чата менеджера (обязательно)
   - `ENABLE_ORDER_NOTIFICATIONS` - включить уведомления (опционально, по умолчанию true)
   - `ORDER_NOTIFICATION_TEMPLATE` - шаблон уведомлений (опционально, по умолчанию default)

## Переменные окружения

- `BOT_TOKEN` (обязательно) - токен Telegram бота от @BotFather
- `MANAGER_CHAT_ID` (обязательно) - ID чата менеджера для получения уведомлений о заказах
- `ENABLE_ORDER_NOTIFICATIONS` (опционально) - включить уведомления о заказах (по умолчанию `true`)
- `ORDER_NOTIFICATION_TEMPLATE` (опционально) - шаблон уведомлений (по умолчанию `default`)
- `BAKER_SCHEDULE_START_DATE` (опционально) - базовая дата начала цикла работы (по умолчанию `2025-01-01`)
- `WORK_CYCLE_ON_DAYS` (опционально) - количество рабочих дней в цикле (по умолчанию `2`)
- `WORK_CYCLE_OFF_DAYS` (опционально) - количество выходных дней в цикле (по умолчанию `2`)
- `WORKING_HOURS_START` (опционально) - начало рабочего дня в часах (по умолчанию `10`)
- `WORKING_HOURS_END` (опционально) - конец рабочего дня в часах (по умолчанию `20`)
- `SLOT_MINUTES` (опционально) - длительность временного слота в минутах (по умолчанию `60`)
- `MIN_LEAD_HOURS` (опционально) - минимальное время до ближайшего слота в часах (по умолчанию `24`)
- `MAX_DAYS_AHEAD` (опционально) - максимальное количество дней вперёд для предзаказа (по умолчанию `14`)
