# Telegram Order Bot (Python, aiogram)

Telegram-бот для автоматизации приёма заказов в кондитерской. Реализует каталог товаров, корзину и многошаговое оформление заказа с выбором способа получения, даты и времени.

## Функциональность

- Каталог товаров с фотографиями и описаниями
- Корзина для выбора товаров
- Многошаговое оформление заказа (FSM)
- Выбор самовывоза или доставки
- Выбор даты и времени с учётом доступных временных слотов
- Автоматические уведомления менеджеру о новых заказах

## Стек

- Python 3.8+
- aiogram
- python-dotenv

## Как запустить

1. Клонировать репозиторий и перейти в папку проекта
2. Установить зависимости из requirements.txt
3. Создать файл .env в корне проекта и указать BOT_TOKEN и MANAGER_CHAT_ID
4. Запустить бота командой `python main.py`
